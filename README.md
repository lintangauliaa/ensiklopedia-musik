# 🪕 Ensiklopedia Interaktif Alat Musik Tradisional Nusantara

Proyek ini merupakan karya Tugas Akhir untuk mata kuliah **Sistem Multimedia**. Website ini menyajikan pengalaman interaktif berbasis web untuk mengenalkan berbagai alat musik tradisional Nusantara menggunakan visualisasi 3D, sampel audio interaktif, peta budaya, dan kuis.

🌐 **Live Demo:** (https://lintangauliaa.github.io/ensiklopedia-musik/index.html)/

---

## ✨ Fitur Utama

* **Ensiklopedia Interaktif 10 Alat Musik:** Menampilkan informasi detail, klasifikasi instrumen, dan daerah asal.
* **Visualisasi 3D Interaktif:** Pengguna dapat memutar, memperbesar (*zoom*), dan melihat detail 360 derajat dari model alat musik.
* **Audio Sample:** Mendengarkan contoh sampel suara khas dari setiap instrumen.
* **Peta Nusantara:** Fitur pemetaan lokasi daerah asal alat musik tradisional Indonesia.
* **Kuis Interaktif:** Uji pengetahuan pengguna mengenai alat musik tradisional Nusantara.
* **Tampilan Responsif & Modern:** Desain antarmuka *edutainment* yang nyaman diakses di berbagai ukuran layar.
